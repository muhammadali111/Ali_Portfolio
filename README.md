# Alex Morgan — Front-End Developer Portfolio

Responsive one-page portfolio built with HTML5, CSS3, JavaScript and Bootstrap 5.

## Folder structure
- `index.html` — website structure and content
- `css/style.css` — custom design and responsive styling
- `js/main.js` — interactions, navigation and demo contact form
- `images/` — local SVG project illustrations

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or open the folder in VS Code and use Live Server.
3. Internet is required for Bootstrap, Bootstrap Icons and Google Fonts CDN resources.

## Customize
Replace `Alex Morgan`, `hello@example.com`, project descriptions and social profile links in `index.html` with your own information.

The contact form is a front-end demonstration only; connect it to a backend or form service to receive messages.
